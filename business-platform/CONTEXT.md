# Business Platform Router

Use this file to route work to the correct workspace.

## Task Routing

| Your Task | Go Here | You'll Also Need |
|-----------|---------|------------------|
| Define the business model | `strategy/CONTEXT.md` | `strategy/docs/business-model.md` |
| Clarify target users or offers | `strategy/CONTEXT.md` | `strategy/vision/business-platform-vision.md` |
| Turn an idea into a feature brief | `product/CONTEXT.md` | relevant strategy docs |
| Create a product spec | `product/CONTEXT.md` | brief from `product/workflows/01-briefs/` |
| Write or change application code | `platform/CONTEXT.md` | related spec from `product/workflows/02-specs/` |
| Define an SOP or business workflow | `operations/CONTEXT.md` | relevant strategy or product docs |
| Create business templates | `operations/CONTEXT.md` | `operations/docs/operating-model.md` |

## Workspace Summary

| Workspace | Purpose |
|-----------|---------|
| `strategy/` | Business direction, customer model, priorities, roadmap |
| `product/` | Ideas become briefs, specs, and build-ready definitions |
| `platform/` | Software architecture, code, integrations, tests |
| `operations/` | Real business processes, SOPs, templates, adoption |

Read the target workspace `CONTEXT.md` before doing substantial work.
