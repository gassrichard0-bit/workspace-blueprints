# MVP Build Plan

## Phase 1: Foundation

- initialize app shell
- set up authentication
- create base layout and navigation
- define database schema

## Phase 2: Sales Core

- lead create, edit, list views
- pipeline stage management
- notes and follow-up tracking

## Phase 3: Client Activation

- convert won deal to client
- onboarding checklist
- client detail page

## Phase 4: Delivery Visibility

- engagement records
- delivery tracker
- overdue and blocked status handling

## Phase 5: Dashboard

- owner dashboard widgets
- urgent items summary
- operational overview

## Phase 6: Hardening

- test core flows
- refine UX
- add basic reporting
