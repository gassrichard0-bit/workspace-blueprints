# MVP Scope

This document defines the first build boundary.

## In Scope

- internal admin login
- lead capture and editing
- pipeline board or stage-based list
- lead-to-client conversion
- client records
- onboarding checklist
- delivery tracker
- owner dashboard

## Out of Scope

- full public marketing site
- client billing and invoicing engine
- complex notifications system
- full automation builder
- deep analytics warehouse
- full mobile app

## Build Standard

The MVP should be useful in real operations, even if rough in design.
The first version wins by replacing messy manual coordination, not by looking complete.
