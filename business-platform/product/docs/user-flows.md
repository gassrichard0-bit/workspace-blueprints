# User Flows

These flows define the first critical journeys.

## Flow 1: Lead to Opportunity

1. user creates lead
2. lead gets initial status
3. owner or sales adds notes
4. next follow-up is set
5. lead advances or is marked lost

## Flow 2: Opportunity to Client

1. opportunity is marked won
2. system creates or prompts creation of client record
3. onboarding checklist is initialized
4. ownership is assigned

## Flow 3: Client Onboarding to Active Delivery

1. onboarding items are completed
2. kickoff is scheduled
3. required documents or inputs are collected
4. onboarding closes
5. delivery workflow begins

## Flow 4: Delivery Monitoring

1. delivery items are created
2. owner updates stage and risk
3. blockers are surfaced
4. overdue items show on dashboard

## Flow 5: Owner Daily Review

1. owner opens dashboard
2. reviews overdue follow-ups
3. reviews stuck pipeline items
4. reviews active clients and delivery risks
5. decides next actions
