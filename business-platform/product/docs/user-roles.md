# User Roles

These roles define the first users the platform should support.

## 1. Owner / Admin

Primary decision-maker. Needs a high-level view and the ability to intervene anywhere.

Needs:

- dashboard with urgent items
- pipeline visibility
- client status visibility
- revenue and workload picture
- ability to update records directly

## 2. Sales / Intake

Owns inbound lead handling and follow-up.

Needs:

- quick lead capture
- pipeline stage updates
- notes and follow-up scheduling
- visibility into stalled deals

## 3. Operations Manager

Owns handoff from sold work to active service delivery.

Needs:

- onboarding workflow
- assignment visibility
- delivery status
- blocked item visibility

## 4. Delivery Lead

Owns actual client work and deliverables.

Needs:

- client context
- delivery milestones
- task ownership
- status updates

## 5. Client

Lower-priority first-phase role.

Potential later needs:

- limited visibility into onboarding or delivery status
- document requests
- milestone progress
