# Module Definition

These are the first conceptual modules of the platform.

## Dashboard

Purpose:

- show what needs attention now

Key widgets:

- leads overdue for follow-up
- deals by stage
- clients onboarding now
- delivery items at risk
- today / this week actions

## Leads

Purpose:

- capture and maintain inbound opportunities

Core fields:

- name
- company
- contact details
- source
- interest / service type
- status
- next follow-up date
- notes

## Pipeline

Purpose:

- show deal progression and expose stuck work

Suggested stages:

- new
- contacted
- qualified
- proposal sent
- won
- lost

## Clients

Purpose:

- hold account-level context after a deal is won

Core fields:

- client name
- primary contact
- active offer
- onboarding state
- delivery state
- account notes

## Onboarding

Purpose:

- standardize the move from won deal to active work

Core objects:

- checklist
- owner
- due dates
- missing items

## Delivery

Purpose:

- track execution of service work

Core objects:

- engagement
- milestone
- task / next action
- due date
- blocker
- current status
