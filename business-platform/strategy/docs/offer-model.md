# Offer Model

The platform should support service businesses first.

## Supported Offer Types

- one-off projects
- recurring retainers
- fixed-scope packages
- ongoing advisory or management services

## Offer Design Requirements

Each offer should eventually map to:

- a sales path
- an onboarding path
- a delivery workflow
- a success definition
- a renewal or closeout path

## Product Implication

The platform should not be built around generic "tasks" alone.
It should be built around the real commercial structure of the business:

- opportunities
- clients
- engagements
- delivery milestones
- follow-up actions
