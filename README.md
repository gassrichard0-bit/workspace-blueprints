# Blockfall

A voxel sandbox that runs entirely in the browser. No install, no account.

**Play:** https://gassrichard0-bit.github.io/workspace-blueprints/blockfall/

- A 256 x 256 x 96 world with generated cities, street grids, highways, ruins and caves
- A drivable car with suspension, per-surface tyre grip and real braking distances
- Mining and building with a 36-slot inventory, dropped items and block hardness
- Day and night with a moving sun, cast shadows, cloud shade and lantern light
- Six buildings, four stories and four worlds built in
- **World codes** — share your code from the pause menu and anyone who enters it
  generates the identical world: same land, same city, same roads

Works with touch (two sticks) or keyboard and mouse. Everything you change is
saved in your own browser.
